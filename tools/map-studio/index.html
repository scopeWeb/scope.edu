বাংলাদেশ তথ্যমানচিত্র

প্রশাসনিক এলাকা বেছে নিন, নিজের তথ্য যোগ করুন, মানচিত্র তৈরি করুন।

এলাকা নির্বাচন

ওয়ার্ড (ইপিআই) স্বাস্থ্যসেবা পরিকল্পনার এলাকা; নির্বাচনী ওয়ার্ড নয়। গ্রাম-সীমানার নির্ভরযোগ্য উন্মুক্ত polygon data পাওয়া যায়নি। বিভাগ → জেলা → উপজেলা → ইউনিয়ন বেছে নিন। ওয়ার্ড আলাদা তালিকায়।

প্রশাসনিক সীমানা

নদীর layer

নদী দেখাতে প্রথম checkbox দিন, তারপর প্রয়োজনীয় level বাছুন।

মানচিত্রের শিরোনাম

নিজের তথ্যের category

একেকটি category একটি map layer। যেমন: হাসপাতাল, স্কুল, আশ্রয়কেন্দ্র, প্রশিক্ষণ কেন্দ্র।

একটি layer বেছে নিয়ে জেলা, উপজেলা বা ইউনিয়ন/ওয়ার্ডে ক্লিক করুন।

Excel থেকে অনেক স্থান যোগ

CSV কলাম: name, latitude, longitude, category, note। Excel থেকে Save As → CSV UTF-8 করুন।

স্থান যোগ করুন

প্রথমে category বেছে নিন, তারপর মানচিত্রে যেখানে স্থানটি আছে সেখানে ক্লিক করুন।
